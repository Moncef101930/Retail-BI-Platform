# Retail-BI-Platform
End-to-End Business Intelligence Platform using PostgreSQL, Talend, Power BI, Python, Machine Learning and n8n.
## Olist E-commerce Business Intelligence Platform

### Overview

Retail BI Platform is an end-to-end Business Intelligence project
based on the Olist Brazilian e-commerce dataset.

The project aims to transform raw e-commerce data into actionable
business insights through data engineering, data warehousing,
Business Intelligence, analytics, and automation.

## Business Problem

The project focuses on analyzing e-commerce performance and answering
key business questions related to:

- Sales performance
- Customer behavior
- Product performance
- Seller performance
- Payment behavior
- Time-based sales trends

## Project Objectives

- Build a complete data pipeline
- Implement a PostgreSQL staging area
- Design and implement a dimensional Data Warehouse
- Develop interactive Power BI dashboards
- Apply Machine Learning for advanced analytics
- Automate selected business processes
